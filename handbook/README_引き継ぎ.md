# 訪看ハンドブック 引き継ぎ書

訪問看護ステーション「いっぽ」(ippo-kango.jp) のスタッフ向け社内ツール。
**手順マニュアル(ガイド)と書類テンプレートが一体になった単一HTMLアプリ**。

- 実体は `index.html` の1ファイルのみ。ビルド不要・サーバー不要・外部依存ゼロ
- `backup_計画記録あり版.html` は旧版のバックアップ(削除済みの計画書テンプレ等を含む。通常は触らない)
- 現在の公開場所: Claude Artifact https://claude.ai/code/artifact/ca17f0ac-bfe5-4962-bdc1-c7df22418f48
- 次の予定: **Netlifyにデプロイし `handbook.ippo-kango.jp` で公開**(下記)

## 実装の重要ポイント（壊さないための注意）

1. **書類データは `DOCS` 配列** — `{id, cat, name, status, tags, desc, items, note}` が基本形。
   - `status`: `'ready'`(入力・印刷できるテンプレ) / `'planned'`(項目リストのみ) / `'guide'`(手順ガイド)
   - ガイドは `flow: [...]` に手順ステップを書くと番号付きで表示される。`itemsTitle` で項目欄の見出しを変更可
2. **入力テンプレは `FORMS` オブジェクト** — 現在3種(hishu=秘密保持誓約書, kaigi=委員会研修記録, motimono=携行品チェックリスト)。
   - `fields` にフォーム定義、`render(v, st)` が印刷用帳票HTMLを返す
   - `fnameBase` がファイル名の先頭部を決める(ファイル名は「名前_書類名_日付」形式)
   - 定型文プルダウンは `PRESET_SETS`(現在GIDAI=委員会議題)。`fields` の `presets:'GIDAI'` で紐づく
3. **人事・労務のパスワードロック** — PWは「ippo」。`LOCKS` にSHA-256ハッシュで保持し、解除状態はsessionStorage(タブ単位)。
   クライアントサイドの簡易保護であり本格的なセキュリティではない(その前提で運用中)
4. **ブラウザ履歴** — 一覧→書類の2階層を pushState/replaceState で維持。読み込み時に `history.replaceState(null,'')` でリセットしている。この処理を消すと「戻る」でアプリごと閉じる不具合が再発する
5. **💾ファイル保存** — Claude Artifact環境では `window.claude.downloads`、それ以外(Netlify等)では通常の `<a download>` に自動フォールバックする。削除しないこと
6. **印刷** — `window.print()` + `#print-area` のみ表示するprint CSS。PDF保存名は `document.title` を一時的に差し替えて実現
7. **テーマ** — CSS変数でライト/ダーク両対応(`prefers-color-scheme` + `data-theme`)。色は必ず変数経由で
8. **noindex設定済み** — `<meta name="robots" content="noindex, nofollow">`。社内ツールのため検索に載せない

## カイポケとの役割分担（重要な設計判断）

- **カイポケ側**: 患者マスタ・計画書・報告書・記録・レセプト・契約帳票(契約書・重説・同意書)
- **このアプリ側**: 手順マニュアルと、カイポケにないスタッフ用書類のみ
- 以前あった患者登録機能・契約書テンプレ類は「カイポケと二重になる」ため**意図的に削除済み**。復活させないこと

- 保存ファイルの命名は「名前_書類名_日付」。Google Driveの共有フォルダに保存していく運用を想定
